# Bookstore schema

This file describes the schema of a fictional bookstore. It describes the entities and relationships between the entities in natural language. It is intended as the input to create a linkml-schema based on the description of the entities. The schema should reside in schema/bookstore.yaml.

The schema must take into account write models and read models. Most slots are both. However some must be computed and the description of the slot will mention this.

## Annotations

The schema uses the following annotations for classes:

- api_resource_name - the lowercase plural version of the entity name (Book -> books)

And the following annotations for slots:

- write_model: boolean - does this slot exist in the request sent to the API?
- read_model: boolean - does this slot exist in the response from the API?
- computed: boolean - is this slot's value persisted or is it computed on retrieval?

## Entities

### Entity

The base entity for this project. Any addressable entity should have is_a: Entity.

#### Entity slots

- id - a uuid generated by the service
- created_at - a ISO-formatted UTC datetime of when the entity was created in the system. This is a infrastructure slot - it is recorded in the database but is not set in the write model or revealed in the read model.

### Person

The base class of a human being.

### Person slots

- name
- gender
- date_of_birth - an ISO-formatted date of when this human was born

### Book

A book sold by the bookstore.

### Book slots

- title - str
- ISBN - a string containing 13 digits
- authors - a non-empty collection of authors of the book
- publisher
- genre - one of the enumeration of:
  - Sci-fi
  - Fantasy
  - Crime
  - Thriller
  - Non-fiction
  - Biography
- reviews - a 0-n collection of Review entities which have been submitted for this book

### Author

A human who has authored books sold by the bookstore. is_a Person.

#### Author slots

- books_published - a collection of books which this author has written
- average_rating - a read-only property which is the average of review scores of books published by this author. A two-digit number with a decimal separator after the first digit such as "0.9", "3.0", "4.3".

### Publisher

An organization who publishes books sold by the bookstore

#### Publisher slots

- name

### User

A customer of the bookstore. is_a Person.

#### User slots

- has_bought: a collection of books which this user has bought
- reviews: a collection of reviews the user has submitted

### Reviews

User-submitted reviews of books in the store.

#### Review slots

- user - the user who authored the review
- score - a rating between 0 and 5 stars
- review_text - an optional free-text field of the user's review of the book
